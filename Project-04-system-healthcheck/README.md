This script is designed to automate basic system monitoring tasks in a Linux (Ubuntu) environment.  
It can be used manually or scheduled using cron for periodic health checks.

---

##  Features

-  CPU Usage Check
-  Memory Usage Check
-  Disk Usage Monitoring
-  Service Status Verification
-  Network Connectivity Check
-  Lightweight and easy to customize

---

## Requirements

- Linux (Ubuntu recommended)
- Bash shell
- Basic utilities:
  - `top`
  - `free`
  - `df`
  - `systemctl`
  - `ping`

---


##  How to Use

1. Clone this repository
   
         git clone 
         cd 

2. Give execute permission
 
         chmod +x healthcheck.sh

3. Run the script

         ./healthcheck.sh
